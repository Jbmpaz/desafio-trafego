# 🚀 Desafio Tráfego – HTML, CSS e JavaScript

Este repositório contém a solução de um **desafio técnico de front-end**, cujo objetivo foi **replicar uma página** utilizando **HTML, CSS e JavaScript**, com foco em estrutura, layout e interações básicas.

O desafio foi originalmente utilizado em um **processo seletivo real**. Mesmo não tendo participado oficialmente, solicitei o desafio para praticar e avaliar meu nível técnico em um cenário próximo ao mercado.

---

## 🎯 Objetivo do Desafio

- Replicar visualmente uma página fornecida como referência
- Implementar interações utilizando JavaScript
- Demonstrar domínio de **HTML semântico**, **CSS** e **JS**

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

## ⚙️ Implementação

  - Fidelidade visual ao layout
  - Clareza de código
  - Foco na interação principal do desafio

---

## 🧠 Abordagem

- Replicação do layout com atenção a espaçamentos e estrutura
- Organização de código para facilitar leitura e manutenção
- Uso de JavaScript apenas onde era realmente necessário

---

## 📂 Estrutura do Projeto

- HTML responsável pela estrutura da página
- CSS para estilização e layout
- JavaScript aplicado exclusivamente ao menu

---

## 📄 Observação

Este projeto tem caráter **educacional e prático**.  
O desafio foi realizado de forma independente, com o objetivo de simular um **teste técnico real de front-end**.
